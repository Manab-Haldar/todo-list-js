# 📝 To-Do List Web App

A simple and interactive To-Do List web application built with HTML, CSS, and JavaScript. Users can add, complete, and delete tasks while enjoying automatic data persistence through Local Storage.

## 🚀 Features

- Add new tasks instantly
- Mark tasks as completed
- Delete tasks easily
- Automatic Local Storage support
- Tasks remain saved after page refresh
- Clean and modern user interface
- Lightweight and beginner-friendly

## ⚙️ How It Works

### Add a Task
Enter a task in the input field and click the **Add** button.

### Complete a Task
Click on any task to mark it as completed.

### Delete a Task
Click the **×** icon beside a task to remove it.

### Save Tasks
All tasks are automatically stored in the browser using Local Storage.

## 📥 Installation

Clone the repository:

```bash
git clone https://github.com/Manab-Haldar/todo-list-js.git
```

Navigate to the project folder:

```bash
cd todo-list-js
```

Open `index.html` in your browser.
